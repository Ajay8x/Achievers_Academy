SECTION 5: BACKEND REST API ENDPOINTS
--------------------------------------------------------------------------------

1. Submit Admission Enquiry (Public):
   POST http://localhost:3000/api/admission
   Body: JSON { studentName, parentName, phone, email, campus, program, hostelRequired, transportRequired, message }

2. List Admission Enquiries (Protected Admin):
   GET  http://localhost:3000/api/admission?campus=all&status=all&search=

3. Export Enquiries to CSV (Protected Admin):
   GET  http://localhost:3000/api/admission?format=csv

4. Admin Authentication (Login):
   POST http://localhost:3000/api/admin/auth
   Body: JSON { username: "admin@achieversacademy.com", password: "Achievers@2025" }

5. Admin Session Check:
   GET  http://localhost:3000/api/admin/auth

6. Admin Sign Out:
   DELETE http://localhost:3000/api/admin/auth

7. Update Enquiry Status & Counselor Notes:
   PATCH http://localhost:3000/api/admin/enquiries/[id]
   Body: JSON { status: "Contacted", notes: "Called parent, visit scheduled" }

8. Delete Enquiry:
   DELETE http://localhost:3000/api/admin/enquiries/[id]

9. AI Virtual Admission Counselor Endpoint:
   POST http://localhost:3000/api/chat
   Body: JSON { message: "Hostel me khana aur rehna kaisa hai?" }
   Features: Multilingual (English, Hindi, Hinglish), Automatic Phone Lead Capture

10. Chatbot Knowledge Base Management:
    GET / POST / DELETE http://localhost:3000/api/admin/kb
