4. Full-Stack Backend Architecture & API Specifications

The backend is architected using Next.js 14 App Router APIs with full type safety, input sanitization, cryptographic session verification, and relational JSON file persistence (data/achievers_db.json).

API Route Method Auth / Security Description & Functional Scope
/api/admin/auth POST SHA-256 + Brute Force Lock Authenticates administrator, generates 7-day JWT token, sets HttpOnly cookie.
/api/admin/auth GET Bearer Token / Cookie Validates active admin session without exposing sensitive hashes.
/api/admission POST Public + Rate Limit (10/min) Validates mandatory fields and 10-digit phone, sanitizes XSS, persists enquiry ID.
/api/admission GET Admin JWT Required Returns filtered enquiries list (by campus, status, query) or instant CSV export.
/api/admin/enquiries/[id] PATCH Admin JWT Required Updates enquiry lifecycle status ('New', 'Contacted', 'Admitted') & counselor notes.
/api/admin/enquiries/[id] DELETE Admin JWT Required Safely removes spam or test enquiry records from the database.
/api/chat POST IP Rate Limit (30/min) Bilingual AI assistant: answers verified queries, extracts mobile leads directly to DB.
/api/admin/kb GET/POST/DEL Admin JWT Required Provides CRUD management for chatbot institutional verified knowledge base.
/api/admin/results GET/POST/DEL Admin JWT Required Manages academic toppers (JEE/NEET/Board) and student/parent testimonials.

6. Top Pop-Up Notification & Comprehensive Error Handling System

In accordance with client instructions, a robust Top Pop-up / Toast Notification Architecture and global error recovery framework has been built and deployed:

  • Top-Floating Notification Banner (ToastContext.tsx): Fixed at top-5 left-1/2 -translate-x-1/2 z-[99999] with slide-down animation (animate-toast-slide-down).
  • Visual Severity Styling:
    • Error Notification: Crimson alert badge, AlertCircle icon, title, error description, and glowing red countdown progress bar.
    • Success Notification: Emerald badge, CheckCircle2 icon, and instant confirmation toast.
    • Warning / Info: Amber & Royal Blue badges for operational notices.
  • Client-Side Real-Time Validation:
    • Admission Page & Modal: Validates student full name, parent name, and 10-digit mobile number format. Rejects invalid inputs with an instant top error pop-up before network transmission.
    • Contact Page: Validates sender identity and phone number format with top error alerts.
    • Admin Login: Displays top error alerts on invalid credentials or account lockout.
  • Next.js Global Error Boundary (src/app/error.tsx): Catches unhandled runtime exceptions gracefully, presenting a recovery card with "Try Again / Reload" and immediate phone/WhatsApp emergency contacts.
  • Custom 404 Route (src/app/not-found.tsx): Cleanly routes lost visitors back to the home portal and admission links.
